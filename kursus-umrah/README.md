# Kursus Umrah — Fahami Ilmu, Hayati Ibadah

Pembentangan HTML interaktif (63 slaid, 16:9) untuk kursus umrah Darul Mubarak Travel & Tours.
Penceramah: Ustaz Zulhafeez Ahmad Zahidi Al-Hafiz.

## Cara buka
Buka `index.html` dalam pelayar (Chrome/Edge disyorkan). Folder `img/` mesti berada di sebelahnya.

## Kawalan
- ← / → atau PageUp / PageDown / Space: sebelum / seterusnya (poin muncul satu demi satu)
- M: menu bab · N: nota penceramah · Home / End: slaid pertama / terakhir
- Butang **Kurangkan Animasi** dan **Mod Cetak** (salinan PDF statik melalui Ctrl/Cmd + P)

## Kandungan
Susunan mengikut slaid asal kursus (folder Drive "Slide Kursus" dan "+Updates").
Transkripsi slaid asal: `TRANSKRIPSI_SLAID_ASAL.md`. Sumber setiap slaid ada dalam nota penceramah.

Kesemua 106 slaid asal telah dibaca. Rujukan mazhab: As-Syafi‘i (slaid asal 75).
