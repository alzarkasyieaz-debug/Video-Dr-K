## H. Teknikal

```bash
cd ep3-seri-iskandar
npx hyperframes check
npx hyperframes render -q delivery -o ../renders/4-isu-seri-iskandar-1080x1920.mp4
```

Bina semula footage (tidak di-commit):

```bash
ffmpeg -i assets/src/c.mp4 -vf "crop=405:720:428:0,scale=1080:1920:flags=lanczos,unsharp=5:5:0.6:5:5:0.0,eq=contrast=1.04:saturation=1.03" -c:v libx264 -preset medium -crf 18 -pix_fmt yuv420p -g 30 -keyint_min 30 -sc_threshold 0 -af "highpass=f=80,lowpass=f=12000,afftdn=nf=-28,acompressor=threshold=-20dB:ratio=2.5:attack=10:release=200,loudnorm=I=-16:TP=-1.5:LRA=9" -c:a aac -b:a 192k -ar 48000 -movflags +faststart ep3-seri-iskandar/assets/footage/dewan-seri-iskandar.mp4
```
