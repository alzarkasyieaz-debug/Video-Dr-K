## Teknikal

```bash
python3 tools/build_isu.py
```

```bash
for i in isu1-pasar isu2-jalan isu3-dataran isu4-rumah; do python3 tools/build_captions_isu.py $i; done
```

```bash
cd ep3-seri-iskandar/isu1-pasar && npx hyperframes check && npx hyperframes render -q delivery -o ../../renders/seri-iskandar-ikut-isu/isu1-pasar-1080x1920.mp4
```

Gantikan `isu1-pasar` dengan nama isu lain untuk render video yang lain. Keempat-empat projek berkongsi `ep3-seri-iskandar/assets/` melalui symlink. Fail footage tidak di-commit; arahan untuk membinanya semula ada dalam `PELAN-SUNTINGAN-SERI-ISKANDAR.md`.

## Perlu anda sahkan

- **SPNB:** transkripsi mendengar “SPMB”. Saya tulis SPNB (Syarikat Perumahan Negara Berhad), syarikat yang melaksanakan Rumah Mesra Rakyat.
- **Satu perkataan tidak jelas** dalam soalan jalan (“tempoh ___ yang ditetapkan oleh KPKT”, 04:01). Subtitle menulis “tempoh …”.
- **“kajian kelayakan”** (sebutan “kelaikan”) dan **“piawaian”** dalam soalan pasar.
- **“Dataran Sungai Seluang”**: sila sahkan ejaan.
- **Angka peruntukan** dalam video jalan (RM69.8 juta, 3.3%, RM60.87 juta, RM480.87 juta) dipaparkan seperti disebut, dan kedua-dua model transkripsi memberi angka yang sama. Angka ini tidak disemak dengan dokumen bajet.
- **Hak siaran RTM.**
- **Tiada muzik latar.**
